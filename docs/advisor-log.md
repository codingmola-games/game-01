# Advisor 판정 로그

매 주요 결정마다 `advisor` 페르소나 호출 → 판정을 여기에 기록. 판정은 수치만 근거로 함.

## 포맷

```
### YYYY-MM-DD · [주제]
- 결정: (한 줄 요약)
- 입력 수치: (DAU / 개발시간 / 매출 / 영상 조회 등)
- 판정: GO / NO-GO / CONDITIONAL
- 조건(CONDITIONAL인 경우):
  1.
  2.
- 사용자 반응: 수용 / 48h 쿨다운 후 오버라이드(반박 1페이지 첨부)
- 재검토 트리거:
```

---

## 오버라이드 규칙 (중요)

- advisor NO-GO 판정 → **48시간 쿨다운** 의무
- 쿨다운 후에도 진행하려면 **1페이지 반박문** 작성 (why the advisor's reasoning is wrong, with counter-numbers)
- 반박문은 이 로그 하단에 부록으로 첨부
- 오버라이드 사실은 해당 주 weekly-report의 "솔직 한 줄"에 반드시 명시

## 로그

### 2026-04-20 · GRAC 사전 상담 결과 (법규 체크포인트)
- 결정: B2C 트랙 즉시 공개 / B2B 경품 이벤트는 전문 법률 검토 후 활성화
- 입력 수치: 상담 회신 1건 (GRAC 051-720-6800)
- GRAC 2단계 답변:
  1. 확률/경품 모두 없으면 등급분류 불필요 — B2C 트랙 적용
  2. "매장에서 5초 정확히 맞추면 식사 무료" 류 실력기반 경품 이벤트는
     **관계 법령(경품표시법·사행행위법 등)을 정확히 들여다봐야 한다**며
     GRAC 단독 판단 보류 — 회색지대 확인
- 판정: **CONDITIONAL**
- 조건:
  1. B2C `EDGE OF ZERO` (경품 無, 확률 無) → **GO** (즉시 공개 가능, Vibe Jam 제출 유지)
  2. B2B 매장 경품 이벤트 → **HOLD**, 다수 관계 법령 정밀 검토 회신 받기 전까지 활성화 금지
     - 공정위 1357 상담
     - 게임전문 변호사 유료 상담 1회 (구체 사례 문의)
     - 공문 서면 질의로 증거자료 확보
  3. Week 2 매장 베타는 **"경품 無 실력 랭킹"**으로만 시작 — 매장 가치는 retention/브랜딩으로 포지셔닝
  4. 경품 이벤트 활성화는 Week 3+ 지연 가능성 수용
- 사용자 반응: 수용
- 재검토 트리거: 변호사/공정위 회신 도착 시 / Week 2 매장 베타 시작 전

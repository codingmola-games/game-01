## 1. 경품표시법 (표시·광고의 공정화에 관한 법률)

**핵심 리스크:** 경품 지급 이벤트는 공정거래위원회 심사 대상. "부당 고가" 판정 시 과징금.

### 규정 요약

- 2016년 소비자현상경품 공식 상한(2,000만원) **폐지됨**
- 그러나 공정위는 여전히 "부당 고가" 기준으로 사후 심사 가능
- 2023~2024년 증권사 고가 경품 사건 등 적발 증가 추세

### 준수 규칙

- **단일 경품 1,000만원 미만** 유지
- **매장 월간 경품 총액 ≤ 매장 월 예상매출의 3%**
- 경품액의 정당성 근거(광고비/예산 비율) 서면화
- 매장별 월 경품액 통계 플랫폼 DB에 기록

### 실력기반 경진 프레이밍 (사행성 회피)

본 플랫폼의 모든 게임은 **측정 정확도 기반 실력 경진**으로 설계.

- 확률형 추첨 아님 → "소비자현상경품" 엄격 규정 일부 우회
- `TERMS.md` 제2조에 명기
- 게임 설명 UI에 "정확도가 높은 순으로 선정" 명시

## 2. GRAC (게임물관리위원회)

**핵심 리스크:** "경품 지급 + 우연성 결합 = 사행성 모사" 판단 시 등급 분류 필요.

### 규정 요약

- 국내 서비스되는 게임물은 GRAC 등급 분류 의무 (예외: 사전 심의 면제 대상)
- 웹 전용(앱스토어 미배포) + 실력기반 + 경품 소액 → **등급 제외 가능성 높음**
- 판단 모호 시 GRAC 사전 상담 **무료**

### 사전 상담 체크리스트

- [ ] GRAC 공식 사이트 확인 (https://www.grac.or.kr/)
- [ ] 게임 설명 1페이지 요약본 준비 (EDGE OF ZERO, TARGET, DUEL, LOBBY, DAILY)
- [ ] 경품 지급 방식 상세 (매장 자율 결정, 월 상한 구조)
- [ ] 실력기반 경진임을 증빙하는 게임 로직 설명
- [ ] 사전 상담 문의: 1577-5396 또는 contact@grac.or.kr
- [ ] 상담 결과를 `docs/advisor-log.md`에 기록 (판정·근거·날짜)

### 사전 상담 전엔 플랫폼 공개 론칭 금지

- Week 0 말까지 상담 완료 목표
- 판정에 따라 등급 신청 여부 결정

### ✅ GRAC 사전 상담 결과 (2026-04-20)

**연락처:** 051-720-6800 (대표번호, 부산)
**질의자:** 코딩몰라 (개인 개발자)
**게임:** `EDGE OF ZERO` (웹 브라우저 타이밍 게임)

**판정 요지:**
> 1. "**확률형 아이템**과 **경품 지급**이 모두 없으면 등급분류 없이 배포 가능."
> 2. "식당에서 5초 정확히 맞추면 식사 무료 제공" 같은 실력기반 경품 이벤트는
>    **관계 법령(경품표시법·사행행위규제법 등)을 정확히 들여다봐야 한다**는 답변.
>    즉 GRAC이 단독으로 OK/NO 판단하는 사안이 아님 — **회색지대**.

**해석:**
- ✅ **B2C 바이럴 트랙 (Vibe Jam 제출본)**: 순수 실력 게임, 확률 요소 없음, 경품 無 → **등급 불필요, 즉시 배포 가능**
- 🟡 **B2B 매장 이벤트 트랙 (경품 포함)**: 회색지대. GRAC 단독 판단 X → **다수 관계 법령 병행 검토 필요**
  - 경품표시법 (공정거래위원회)
  - 사행행위 등 규제 및 처벌 특례법 (경찰청)
  - 게임산업법 (GRAC · 사행성 여부)
  - 경우에 따라 옥외광고물법·식품위생법 등

**Week 1 내 보강 액션:**
1. **공정위 경품표시법 상담** (국번없이 1357, 공정위 소비자 상담)
2. **경찰청 사행성 관련 유권해석** 필요 시 문의
3. **게임전문 변호사 1회 유료 상담** (30분 ₩100,000 내외) — "실력 정확도 기반 매장 경품 이벤트" 구체 사례로 문의
4. **공문 질의** 제출 → 서면 회신을 `docs/LEGAL.md` 증거자료로 보관

**즉시 영향:**
- Vibe Jam 제출본 및 `pages.dev` 공개 → **문제 없음**
- Week 2 매장 베타 시작 시 → **경품 無 실력 랭킹**으로만 시작
- 경품 이벤트는 **전문 법률 검토 회신 받은 뒤에만** 활성화 (Week 3+ 지연 가능)
- 매장 사장님께 사전 안내: "법률 검토 중이라 초기 베타는 경품 없이 실력 랭킹으로 시작합니다"

## 3. 개인정보보호법 (PIPA)

**핵심 리스크:** 휴대폰번호 등 개인정보 수집 시 위반 가능성. 과징금 매출 3%.

### 수집·처리 원칙

- **최소수집:** 당첨자에게만 휴대폰번호 요청. 참가자 전원 X
- **목적 제한:** 경품 발송 목적으로만 사용. 마케팅 DB 전환 금지
- **저장:** 뒷자리 4자리 마스킹(예: `010-1234-****`) 후 보관
- **삭제:** 경품 발송 완료 후 **24시간 내 완전 삭제**
- **제3자 제공:** 기프티콘 발송 대행(카카오 for Biz 등) 시 **명시적 동의** 필수

### 동의 UI 요건 (`TERMS.md` 및 이벤트 참여 흐름)

- 수집 항목 명시 (이름, 휴대폰번호 뒷4자리 등)
- 수집 목적 명시 (경품 발송)
- 보관 기간 명시 (경품 발송 후 24h)
- 제3자 제공 대상 명시 (해당 시)
- 동의 거부권 명시 (거부 시 당첨 불가)

### 감사 로그

- 매 이벤트 종료 후 `docs/privacy-audit.log` 에 기록
  - 이벤트 ID, 수집 건수, 발송 건수, 삭제 건수, 삭제 타임스탬프
- 월 1회 감사 (플랜 `/advisor` 세션에 포함)

## 4. 광고 표시 및 쿠키 동의 (방통위 / KISA)

**핵심 리스크:** 광고 미표시 / 쿠키 무단 사용 시 방통위 제재.

### 준수 규칙

- **모든 광고 구간에 "(광고)" 표기** — 인앱 배너, 스폰서 슬롯, 리더보드 광고 포함
- **쿠키 동의 없으면 추적성 스크립트 inject 금지** — Adsterra, Analytics 등
- **쿠키 동의 배너**는 첫 방문 시 노출 (cookieconsent.js vanilla)
- 수신거부·쿠키삭제 옵션 명확히 제공
- 광고주명·연락처를 "(광고)" 표기 인접 영역에 명시

### 구현 체크리스트

- [ ] `index.html`에 쿠키 동의 배너 삽입 (Week 0 말)
- [ ] `consent=yes` 쿠키 설정 전엔 Adsterra/Analytics 스크립트 inject X
- [ ] 스폰서 슬롯 렌더 시 상단에 "(광고) - [광고주명]" 라벨
- [ ] 설정 페이지에 쿠키 재설정·삭제 버튼 제공

## 2. 개인정보보호법 (PIPA)

**핵심 리스크:** 개인정보 수집 시 위반 가능성. 과징금 매출 3%.

### 수집 범위 (v6 최소화)

- **접속 로그:** IP, User-Agent, 시각 (분석·어뷰징 차단 목적)
- **게임 이용 데이터:** 닉네임(선택), 점수, 플레이 시간 — 비식별
- **이메일:** 문의 보낼 때만 수신

### 수집하지 않는 것

- 실명, 주민번호, 주소, 휴대폰번호
- 결제정보 직접 저장 (카카오페이 송금은 외부 서비스에 위임)

### 경품 관련 수집 조항은 v6에서 **불활성** 상태로 남김

(향후 정책 바뀔 때 되살릴 수 있도록 PRIVACY.md의 "이벤트 당첨자 한정" 섹션은 보존. 현재는 실제 수집 플로우 없음.)

## 3. 광고 표시 및 쿠키 동의 (방통위 / KISA)

**도입 시점:** Week 4+ (Adsterra, DAU 100+ 조건 충족 시에만)

### 준수 규칙 (도입 시 적용)

- 모든 광고에 "(광고)" 표기
- 쿠키 동의(`consent=yes`) 없으면 추적 스크립트 inject 금지
- cookieconsent.js 배너 이미 `index.html` 삽입됨
- Adsterra 같은 네트워크 이름·(광고) 라벨을 배너 인접에 명시

### v6 상태

- 현재 광고 스크립트 없음 → 이 조항 대기 상태
- DAU 100+ 미달 시 영구 스킵 → 조항 적용 안 함

## 4. 사업자등록 및 세무

### v6 결론: 현 시점 **사업자등록 불필요**

**이유:**
- 매장 B2B 트랙 폐기 → 카카오 for Biz·기프티쇼 Biz 가입 불필요
- 카카오페이 개인 송금 = 사업자등록 없이 수령 가능
- 유튜브 AdSense·쿠팡파트너스는 개인 자격으로 운영 가능

### 수입이 유의미해지면 (참고)

- 종합소득세 신고 (매년 5월) — 일정 기준 초과 시
